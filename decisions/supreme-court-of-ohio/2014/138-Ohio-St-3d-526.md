# State v. Taylor

## Majority

{¶ 3} 2013-0141. State v. Wilson, 2d Dist. Montgomery No. 25057, 2012-Ohio-5912, 2012 WL 6561009.
{¶ 4} 2013-1105. State v. Boltz, 2013-Ohio-1830, 991 N.E.2d 726 (6th Dist.).
{¶ 5} 2013-1456. State v. Jenkins, 2d Dist. Montgomery No. 25414, 2013-Ohio-3038, 2013 WL 3776388.
O’Connor, C.J., and Pfeifer, O’Donnell, Lanzinger, Kennedy, French, and O’Neill, JJ., concur.
